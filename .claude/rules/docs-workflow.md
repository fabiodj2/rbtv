# Docs and memory
- Behavior change => update the numbered doc; new topic => next number, linked from README status table.
- Record artefact md5s when a deployed binary changes (see docs/16 §1).
- Session notes in `docs/sessions/YYYY-MM-DD-topic.md`: what worked (with evidence), what failed, what is left. Never put secrets in them.
- New `.md` files go under `docs/` (hook-enforced).
