# Delegation and models (token economics)
- Haiku: file search, docs edits. Sonnet: default for scripts/C changes and reviews. Opus: audio-pop/crash debugging, security-critical flashing logic, architecture.
- Escalate to Opus when the first attempt failed or the task spans 5+ files.
- Give subagents the objective, not just the query; evaluate their return and follow up (max 3 loops).
- Keep few MCPs enabled; prefer CLIs wrapped in skills over always-on MCPs.
